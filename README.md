# Cinematic Interior Design Portfolio

This is the starter repository for an ultra-premium, cinematic, fully dynamic portfolio website for an Interior Design Architect — built with Next.js, React Three Fiber, Framer Motion, Tailwind CSS, and a real-time intelligent color engine.

---

## Features
- Scene-based smooth scroll and cinematic transitions
- Immersive 3D environment as hero
- Dynamic color grading engine (theme adapts to project images)
- Next-gen gallery and storytelling sections
- Luxury minimal UI — inspired by the world’s best architecture studios

## Tech Stack
- Next.js App Router
- React Three Fiber (3D)
- Framer Motion (animation)
- Tailwind CSS (UI)
- GLSL shaders (FX)
---

## Getting Started
1. `npm install`
2. `npm run dev`
3. Start building your cinematic portfolio!

---

Customize the `/public/assets/images` and `/src/scenes` folders with your designs and models.
